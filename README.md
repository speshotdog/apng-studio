# APNG Studio 使用說明

APNG Studio 是給 Clip Studio Paint 動態貼圖使用的排幀與匯出工具。它會在匯出前依照 APNG 與 LINE 驗證器的實際算法檢查影格，避免 apngasm 顯示的張數和 LINE 收到的張數對不上。

## 怎麼開啟

下載 `APNG-Studio-x.y.z-portable.exe`，點兩下即可使用，不需要安裝。

## 基本流程

1. 把 `.clip` 檔拖進視窗。
2. 按影格軌上的「帶入 CSP 時間軸」，或從左側把圖層拖到下方影格軌。
3. 影格中間可以留空，空格會自動延續前一格的圖片。
4. 按播放，直接確認速度與動畫效果。
5. 在右側設定輸出尺寸、FPS 與播放次數。
6. 選擇 APNG 或 GIF，按匯出。


## 為什麼兩種幀數不一樣？

「時間軸格數」是你排了幾格；「實際 APNG 幀數」是檔案真正包含幾幀。連續一樣的圖片會被合併成一幀，並把停留時間加長。這是 APNG 規格與 LINE 驗證器的行為，不是工具算錯；以前 apngasm 張數對不上，原因就是這個。

## LINE 動態貼圖規格速查

| 項目 | 限制 |
|---|---|
| 貼圖尺寸 | 最大 320 × 270 px，寬或高至少一邊為 270 px |
| 幀數 | 5–20 幀（以實際 APNG 幀數計算） |
| 單次播放 | 1、2、3 或 4 秒 |
| 播放次數 | 1–4 次，總播放時間最多 4 秒 |
| 檔案大小 | 1 MB 以內 |
| 格式 | APNG（`.png`）、透明背景 |
| 主要圖片 | 240 × 240 px |
| 聊天縮圖 | 96 × 74 px |

「帶入 CSP 時間軸」會讀取 CSP 原本的動畫資料夾與關鍵影格。工具只在關鍵影格填入對應的同名 cel 資料夾；中間空格會自動延續前一格，因此排幀畫面簡潔，播放結果仍與 CSP 時間軸一致。

## 匯出檔名

存檔對話框的預設檔名是**月日_時分**，例如 8 月 23 日 03:19 匯出就是 `0823_0319.png`，
並且預設存在原本 `.clip` 檔的同一個資料夾。連續匯出多版不會互相覆蓋。

## 給開發者

本專案為了不散布委託人的原稿，`assets/samples/`（測試用 `.clip`）與
`assets/golden/`（由它產生的比對基準圖）**未包含在 repo 內**。
因此 clone 之後 `npm run verify` 與 `npm run smoke` 需要自備 `.clip` 檔並自行建立基準。

```bash
npm install
npm run dev      # 開發模式啟動
npm run dist     # 打包 Windows exe 到 release/
```
